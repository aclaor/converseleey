Roleplay · unlimited · your key · build 11

Have the conversation before you have to.

An AI character plays the other person — the interviewer, the manager, the date — and stays in role. It won't coach you mid-scene, because nobody does that in real life. When you end it, it breaks character and tells you what you actually did.

It runs straight from your browser to whichever provider you pick, using your own key. Three of the four have a genuinely free tier, so this can cost you nothing.

Get a key

The key is stored only in this browser, on this device. It goes nowhere except directly to the provider you chose. There is no server behind this page — nobody, including whoever built this site, can see it.

If a provider refuses Calling these APIs straight from a web page only works if the provider allows it. Some do, some don't, and none of them promise either way in writing. If one is blocked you'll get a clear message saying so — just pick another from the list. It takes about thirty seconds to find one that works.
Sensible precautions Make a separate key just for this rather than reusing one from another project, and don't paste a key into any page on a shared or public computer. You can delete it from this browser at any time with the button on the next screen.

Voice settings

Every phone and computer ships different voices. The best one here is picked for you, but the list is worth a scroll — quality varies enormously.

This sounds close to human, and it costs money per minute spoken — roughly five to fifteen cents. The key stays in this browser. If it ever fails mid-scene, the device voice takes over rather than leaving you in silence.
