Roleplay · unlimited · your key

Have the conversation before you have to.

An AI character plays the other person — the interviewer, the manager, the date — and stays in role. It won't coach you mid-scene, because nobody does that in real life. When you end it, it breaks character and tells you what you actually did.

This runs directly from your browser to Anthropic using your own API key. That means it's genuinely unlimited: no daily cap, no trial, no upgrade prompt. It also means the cost is yours, and it's small — a full scene plus coaching is typically well under a cent.

Get a key

The key is stored only in this browser, in local storage on this device. It is never sent anywhere except directly to Anthropic's API. There is no server behind this page — nobody, including whoever made this site, can see it.

Sensible precautions Create a separate key just for this rather than reusing one from another project, and set a spend limit on it in the Anthropic console. Don't paste a key into any page on a shared or public computer. You can delete the key from this browser at any time with the button that appears once it's saved.
